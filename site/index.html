Every agent is untrusted

Least privilege is the default, and only you can change it. The security model.

  • SandboxedBubblewrap, its own folders, listed hosts only.
  • No keys insideA proxy adds tokens on the way out.
  • Guards that always holdEven in Bypass, which is off by default.
  • Yours aloneThe EA and agents cannot touch security settings or secrets.
  • Closed by defaultLoopback only, behind a passkey, a token or Cloudflare Access.
  • AuditedEvery action lands in a verified hash chain.

Install in one line

Linux with systemd; Ubuntu 24.04 is the reference. Run it as a user with sudo.

Install on Linux Tap to select 
$ curl -fsSL https://raw.githubusercontent.com/rickaym/seti/main/scripts/install.sh | bash -s -- --with-redis --with-ea

Drop --with-redis and --with-ea for the smallest install. Voice needs OpenAI, Deepgram and ElevenLabs keys.

  1. Open a new shell, then sign in to Claude Code (claude, then /login) and to GitHub (gh auth login).
  2. Open http://seti.localhost:3006. From another machine, forward the port with ssh -L 3006:127.0.0.1:3006 <host>.
  3. Sign in with the token that cat ~/.seti/credentials/local-token-user prints.
  4. Add a repo in Settings, Repos, then start an agent.
