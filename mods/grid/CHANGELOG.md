# Changelog

## 1.1.0

Alt+Arrows no longer move focus between panels; Vim mode is the one way to move between panels by keyboard. Alt+Shift+Arrows still move the focused panel.

## 1.0.1

Only the shell in a terminal tile takes every key; the tile around it is an ordinary panel, so Vim mode's keys work on it.

## 1.0.0

The agent grid moves out of Seti's core into this mod, on by default.
