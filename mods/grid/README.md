# Grid

Shows agents and terminals side by side in panels you drag, resize and tidy. Each workspace keeps
its own layout, shared by every device; whether the grid is on is up to each device.

## Use

- Grid in the Agents header, Alt+G or Agent grid in the palette turns the grid on and off.
- Open in grid in an agent's header puts that agent in a panel.
- Drag an agent from the list onto the grid, or pick one in an empty panel.
- Drag a panel by its header and resize it by its edges; Lock keeps the layout still.
- Tidy lays the panels out evenly, and the template picker sets how many fit one screen.
- Terminal adds a shell as a panel of its own.
- Alt+Arrows move between panels, and Alt+Shift+Arrows move the focused panel.

Phones always show one agent at a time.

## When it is off

Every device shows one agent at a time, and the grid's keys and buttons are gone. Saved layouts
stay, and come back when the grid is turned on again. Terminal tiles leave the terminal lists while
it is off, and their shells end 15 minutes after their last window closed.
