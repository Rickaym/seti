# Changelog

## 1.1.0

On a wide screen the Pad icon opens the pad as a window over the page, which you drag by its header,
resize from its edges and corners, and move or resize with the arrow keys. Each device remembers
where it is and whether it is open. Needs mod API 1.27.

## 1.0.0

A text pad at the bottom of the navigation that saves itself, with read and append actions for the
EA. Needs mod API 1.26.
