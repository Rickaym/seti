# Poller templates

Gives a new poller a script to start from, so you fill in a URL instead of writing the script.

## Templates

- **HTTP JSON** polls a JSON API. Set the URL, the path to the list, and the fields that hold each item's key and title.
- **RSS/Atom feed** polls a feed. Each entry becomes an item keyed by its id or link.

Pick a template in Settings, Channels, New poller. The script stays yours to change afterwards.
