# Previews

Shows PDFs page by page, CSV files and workbooks as tables, and Mermaid diagrams in files, Markdown and transcripts.

## Use it

Open a .pdf, .csv, .tsv, .xlsx, .xls, .ods, .mmd or .mermaid file in an agent's Files panel. A PDF is fitted to the width and zoomable. A table filters its rows and copies what you selected, and a workbook shows each sheet in its own tab. A diagram zooms, shows its source and exports as SVG or PNG. Mermaid fences in Markdown files and transcripts draw as diagrams too.

Each format loads the first time a file of that kind opens, and workbooks are read in a background worker, so a large file never freezes the page.

## Settings

Each format has its own switch: PDF, Spreadsheets and CSV, and Mermaid. Turning one off takes effect at once and leaves the others on.

## While a format or the mod is off

CSV files and diagrams open as text, Mermaid fences show as code, and PDFs and workbooks offer their download. A line above the file names the switch or the mod, with one tap to turn it back on.
