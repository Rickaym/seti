# Changelog

## 1.1.0

Mermaid fences in Markdown zoom in and out and fit back to the width. Sharing a Markdown file or a diagram file draws its diagrams for the share page, which shows them as light and dark images with Fit, 100% and 200% zoom.

## 1.0.0

The first version, bundled with Seti. It combines the PDF, Sheets and Mermaid mods, with a switch per format.
