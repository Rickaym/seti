# Catppuccin

Catppuccin is a soothing pastel theme. Seti shows Latte when your device is light, and Frappe, Macchiato or Mocha when it is dark.

## Use it

Pick Catppuccin in Settings, General, Theme. The Dark flavour control picks the dark palette, and Accent picks one of fourteen colours for buttons, links and focus rings.

Every colour pair meets WCAG AA contrast for text, in every flavour and accent.

## What it may do

Nothing beyond colours: a theme mod is a set of token values with no code.
