# **NAME**

A Seti mod. `pnpm mod build` bundles `src/logic.ts` into `logic.js`, `pnpm mod test` runs the tests
against a fake Seti, and `pnpm mod check` prints what the consent screen will say. Seti reads only
the files `seti-mod.json` names and never runs install scripts. This README is the mod's Details
tab in Settings, Mods; `icon` may name a lucide icon or an `.svg` or `.png` file here.
